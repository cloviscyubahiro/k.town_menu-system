# K.Town menu and ordering system

Digital menu, table ordering, reception, kitchen and owner dashboards for K.Town Liquor Boutique, Gitesi, Karongi.

| Folder | What it is |
|---|---|
| `KTown-Digital-System/` | Version 1: the working prototype used for presenting (plain HTML/JS, data kept in the browser). Open `START-HERE.html`. |
| `docs/database-design.md` | Design of the database for version 2 (React + Node.js + SQLite) |
| `database/` | The SQLite schema, reference data and tests for version 2 |

Version 2 is being built in this order: database (done, for review), API design, Node.js backend, React frontend, pilot at K.Town.
